# Nalarva v5 — Academic Workflow

## Perubahan utama
- Dashboard Admin/Tutor/Siswa memakai data backend nyata, bukan angka contoh.
- Pengaturan akun dan ganti password untuk semua role.
- Admin dapat reset password dan mengaktifkan/menonaktifkan akun siswa/tutor.
- Kapasitas kelas divalidasi backend.
- Enrollment dapat dilihat, difilter, dinonaktifkan, dan diaktifkan kembali.
- Tryout dapat dipublish/draft dari dashboard admin.
- Bank Soal dapat melihat susunan soal per tryout dan menghapus item dari tryout tanpa menghapus bank soal.
- Tryout siswa: timer, navigasi nomor, tandai ragu-ragu, autosave browser, resume attempt, submit otomatis ketika waktu habis, konfirmasi soal kosong.
- Hasil tryout menyertakan review jawaban dan pembahasan.
- Ukuran teks readable v4.2 tetap dipertahankan.
