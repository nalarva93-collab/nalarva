# Changelog v9

## Profil
- Data siswa: HP, tanggal lahir, kelas sekolah, kota, alamat.
- Data orang tua/wali: nama, hubungan, WhatsApp, email.
- Nama siswa dapat diperbarui dari profil.

## Kalender Akademik
- Admin membuat event global / program / kelas.
- Tutor melihat event kelas/program terkait.
- Siswa melihat event kelas/program terkait.
- Event kelas baru membuat notifikasi kepada siswa dan tutor yang terhubung.

## Pesan
- Tutor hanya dapat mengirim ke siswa dari kelasnya.
- Siswa hanya dapat mengirim ke tutor dari kelasnya.
- Inbox/outbox sederhana.
- Status dibaca.
- Notifikasi pesan masuk.
