# Nalarva v6 — Commercial Workflow

## Ditambahkan
- PACKAGES, ORDERS, dan PAYMENTS pada Google Sheets.
- Paket belajar dapat dibuat/diubah dari dashboard Admin.
- Paket berstatus ACTIVE otomatis tampil di halaman publik /paket.
- Pendaftaran website dapat dibuatkan tagihan.
- Pembayaran manual/transfer/QRIS manual dapat dikonfirmasi Admin.
- Setelah pembayaran PAID, Admin dapat mengaktifkan calon siswa menjadi akun SISWA.
- Aktivasi membuat profile siswa, program, dan opsional enrollment ke kelas.
- Password sementara hanya dibuat jika email belum mempunyai akun siswa.
- Status pendaftaran: BARU, DIHUBUNGI, MENUNGGU_PEMBAYARAN, AKTIF, BATAL.

## Tidak ditambahkan
Payment gateway otomatis belum dipasang. v6 sengaja memakai konfirmasi pembayaran manual agar biaya dan kompleksitas awal tetap rendah.
